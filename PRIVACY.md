# Privacy Policy

CCBeep does not collect, store, transmit, or share any data.

- **No network access**: The plugin never makes outbound network requests.
- **No analytics**: No usage data, telemetry, or analytics are collected.
- **No logging**: No user input, file paths, or system information is logged.
- **Local only**: All sound configuration is stored in `~/.ccbeep.json` on your machine. The mute flag is stored in `~/.ccbeep_mute`.

CCBeep is a shell script that uses only system built-in audio tools (`afplay`, `paplay`, `aplay`, or `[System.Console]::Beep`). It runs entirely on your local device.
